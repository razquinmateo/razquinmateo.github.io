Mis proyectos

Lalo Servicios

Sitio web para venta y alquiler de maquinaria de construcción, usando HTML, CSS, JS, Bootstrap y SweetAlert2.

Stockify

Sitio web creado para creado para solucionar la problematica del control de stock. Desarrollado durante el 5to semestre de la carrera de TI.
Tecnologías destacadas: Angular y Springboot.

Sudoku!

Aplicación web para jugar al Sudoku, con un diseño limpio y moderno. Utiliza HTML, CSS, JS y Bootstrap.

PokeApi V2

Aplicación web que consume la popular PokeAPI, mostrando información de Pokémones, habilidades y tipos. Además permite buscar Pokémon por nombre, filtrar por tipos o generación y una sección de favoritos.

TMDB API

Aplicación web que consume la API de The Movie Database (TMDb) para mostrar películas populares, buscarlas por nombre o género, y ver detalles completos en múltiples idiomas. Desarrollada con React, Tailwind y React Router.

Ahora Caigo Web

Recreación del popular programa de televisión "Ahora Caigo" en formato web. Desarrollada con Html, CSS, JS y Bootstrap.

Carlink

Marketplace de alquiler de vehículos entre particulares, con mapa interactivo, reservas por hora o día y pagos integrados. Desarrollado con Laravel, Livewire, Filament, MySQL, Cloudinary y MercadoPago.

CreateRooms

Extensión de Chrome para docentes que usan Google Meet con salas de grupos de trabajo: guarda la composición de equipos de alumnos y la reaplica automáticamente en las próximas clases. Desarrollada en JavaScript (Manifest V3).

LaloSueldos

Aplicación de escritorio para la gestión de horarios y sueldos de empleados, con respaldo automático de datos. Desarrollada en Python con interfaz Tkinter y base de datos MySQL.
